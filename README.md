# 안성교회 서적부 카탈로그

카탈로그 주소: **https://keonchue.github.io/seojeokbu-catalog/**

책 이름·사진·분류 같은 기본 정보는 **`books.csv`** 한 파일만 고치면 됩니다. 고쳐서 Commit 하면 1~2분 뒤 위 주소에 반영됩니다.

## 가격·할인은 서적부 POS 앱이 정합니다
서적부 POS 앱에서 책에 **카탈로그 번호**를 이어 두면(설정 → 카탈로그 연결), 그 책의 가격과 할인율은 앱 값이 카탈로그에 바로 보입니다.
앱에서 가격이나 할인을 바꾸면 카탈로그도 같이 바뀝니다. 그런 책은 `books.csv` 의 가격 · 반값할인 칸을 고쳐도 화면에 안 나옵니다.
앱에 이어지지 않은 책, 또는 앱 가격표를 못 읽었을 때는 `books.csv` 값이 보입니다.

## books.csv 고치는 법
1. 파일 목록에서 `books.csv`를 누릅니다 (표로 보입니다).
2. 오른쪽 위 연필 아이콘을 누르면 글자로 바뀝니다. 한 줄이 책 한 권이고, 칸은 쉼표(,)로 나뉩니다.
3. 고친 뒤 초록색 **Commit changes**를 누릅니다.

| 칸 | 적는 법 |
|---|---|
| 번호 | 책 번호. 겹치면 안 됩니다. |
| 분류 | 아래 분류 이름 중 하나를 그대로 |
| 이름 | 책 이름. 이름에 쉼표가 있으면 "따옴표"로 감쌉니다. 예: `"하루 한 장 성경필사, 시편"` |
| 색상 / 번역 | 없으면 비워 둡니다. |
| 가격 | 숫자만 (예: 12800). 0이면 '가격 문의'. 앱에 이어진 책은 앱 가격이 이깁니다. |
| 할인도서 | 할인 도서 칸에 넣을 책이면 `O` (빨간 '할인가 : ○원'으로 표시) |
| 반값할인 | 50% 할인 성경이면 `O`. 앱에 이어진 책은 앱의 할인율이 이깁니다. |
| 목록으로 | 사진 없이 맨 아래 '그 외 책들' 목록에 넣을 책이면 `O` |
| 사진 | `img` 폴더의 표지 파일 이름 (예: 077.jpg). 없으면 비워 둡니다. |
| 참고사진 | 실물과 조금 다른 참고 사진이면 `O` |

- **분류 이름**: 개역개정 성경 / ESV 한영 성경 / 어린이 성경 / 개역한글 성경 / 새번역 · 현대인 · 대조 성경 / 한영 · 영어 성경 / 어린이 도서 / 일반 도서 / 찬송가 · 기타
- **책 빼기**: 그 줄을 지웁니다. **책 넣기**: 맨 아래에 새 줄을 씁니다. 같은 분류 안에서는 줄 순서대로 보입니다.
- 쉼표 개수가 틀리면 그 줄 칸이 밀립니다. 다른 줄을 보고 쉼표 개수(10개)를 맞춰 주세요.
- 엑셀로 열어서 고친 뒤 'CSV UTF-8' 형식으로 저장해 다시 올려도 됩니다.

## 그 밖의 파일
- `index.html`: 카탈로그 화면과 상세페이지 내용(크기·쪽수·책 소개). 고칠 게 있으면 Claude에게 말해 주세요.
- `img/`: 표지 사진 (파일 이름 = 번호.jpg)
- `detail/`: 상세페이지 사진
